# 抽卡小游戏 · 修仙抽卡模拟器

基于 Cocos Creator 3.8 开发的 2D 抽卡模拟器网页版。

## 在线预览

https://js-jc.github.io/chouka-minigame/

## 玩法

- 单抽 / 十连抽
- 保底机制：5 星基础概率 2%，第 51 抽起每抽递增 2%，最高 100%
- 钻石经济：单抽 280 钻，十连 2800 钻，充值 +6480 钻
- 数据统计：累计 5 星数、出金率、保底进度、理论期望

本仓库为 Cocos Creator 构建产物（web-mobile），仅用于在线预览，源码不在此仓库。
